# 事件与灰度视频导出助手

面向 Windows 的 Python/Tkinter 手动导出工具。读取 DAVIS 相机录制的 AEDAT4，在共同时间范围内生成同一播放时间轴的视频，不连接或控制相机。

当前为实验性源码版本，不是免安装 EXE。

## 功能

- 手动多选 AEDAT4，逐文件排队处理。
- 勾选联合视频、黑底红绿事件视频、灰度视频中的一种或多种。
- 输出帧率 1～500 FPS，默认 30 FPS。
- 输出 H.264 MP4、时间对应 CSV、联合预览和 JSON 报告。
- 转换在独立进程中执行，界面显示阶段及编码进度。
- 原始文件只读，转换前后核验 SHA-256；不覆盖已有输出目录。
- “取消后续任务”不会中断当前文件；当前文件完成后停止队列。

## 安装与启动

建议使用 Windows 64 位 Python 3.10 或 3.11，并包含 Tkinter。记录的本机验证环境为 Python 3.10.9、Tk 8.6.12；依赖版本见 requirements.txt。其他环境尚未完整验证。

下载并解压项目，在包含 requirements.txt 的目录打开终端，执行：

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

如果安装的是 Python 3.11，将第一条中的 `-3.10` 改为 `-3.11`。创建虚拟环境和安装依赖只需执行一次，需要联网下载依赖；不需要激活环境或修改 PowerShell 执行策略。

之后双击 `启动助手.cmd`。如窗口意外退出，可在终端执行以下命令查看错误：

```powershell
.\.venv\Scripts\python.exe event_export_assistant.py
```

本机原有桌面快捷方式属于本地安装，不随仓库发布。

## 使用

1. 先在采集软件中停止录制，等待 AEDAT4 写入结束。
2. 打开助手，点击“选择录制文件（可多选）”。
3. 选择输出目录、输出类型和帧率。
4. 点击“开始导出 / 重试失败项”。
5. 完成后点击“打开选中结果 / 输出目录”。失败时选中记录查看原因。

每个录制建立独立的输出子目录。即使只选择一种视频，仍保存时间对应表、联合预览和报告。

```text
01 事件与灰度联合视频.mp4   # 勾选时生成
02 红绿事件视频.mp4         # 勾选时生成
03 灰度视频.mp4             # 勾选时生成
04 时间对应表.csv
05 联合画面预览.png
06 转换结果.json
联合编码日志.txt
```

已完成的记录不会在同一队列中重复处理；如需改变参数再次导出，移除该记录后重新添加。

## 同步与数据限制

- 输入必须有且仅有一路事件流和一路灰度流，并且两路都含实际数据；即使只输出事件视频，目前也要求录制含灰度数据。
- 仅支持无偏移、尺寸一致且宽高均为偶数的 8 位灰度 APS 帧。
- 事件按固定输出时间窗累积，每个像素只保留该窗口最后一次事件的极性，正事件绿、负事件红，无额外滤波。
- 灰度选择曝光中点最接近事件窗口中心的原始帧，可能重复或跳过原始帧。
- 多路视频具有相同的播放时间轴，不等于事件窗口与灰度曝光区间严格相同；偏差及重复记录在 CSV 中。
- 500 FPS 是视频输出帧率，不会提高相机原始灰度采样率。高帧率增加编码工作量，播放器也不一定支持流畅播放。
- MP4 为有损可视化结果，不应替代 AEDAT4 原始数据作为唯一训练来源。
- 使用系统临时目录缓存解码后的事件、时间戳和灰度像素，可能明显大于原始压缩文件；需留足系统临时磁盘和输出磁盘空间。曝光元数据仍保存在内存中，未做超长录制压力验收。
- 请勿转换仍在写入的录制。文件变化检查不能代替停止录制。
- 失败可能留下不完整输出，程序不会自动删除，未生成成功报告的结果应视为未完成。
- 转换报告包含本地源文件绝对路径，分享报告前请检查个人信息。

## 已完成与待完成的验证

已实际运行转换子进程并完整解码输出：

- 30 FPS 样本：三路各 300 帧，逐帧播放时间戳一致。
- 500 FPS 样本：三路各 3122 帧，逐帧播放时间戳一致。
- 单独输出事件、只输出联合及灰度的组合已验证。
- 无实际灰度数据的输入明确失败，不创建输出目录。
- 已有输出目录会被拒绝，源文件哈希检查通过。
- 窗口布局和 Windows 原生对勾已截图检查。

尚未完成：从原生文件选择框到队列完成的完整 GUI 自动验收、取消队列流程、大文件压力测试及全新电脑安装验证。不要把上述 CLI 验证理解成完整界面流程或所有平台已通过验收。

## 命令行

```powershell
.\.venv\Scripts\python.exe aedat4_joint_video.py "录制.aedat4" --output-dir "新的输出目录" --fps 30 --types joint events gray
```

`--types` 可使用 `joint`、`events`、`gray` 的一种或多种组合。
